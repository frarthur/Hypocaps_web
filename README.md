# Hypocaps

Site web du projet Hypocaps — une solution de resucrage au goût neutre pour les personnes atteintes d'hypoglycémie.

## À propos

Hypocaps est un projet visant à rendre la vie des personnes atteintes d'hypoglycémie plus simple en proposant une solution de transport ainsi qu'une solution de resucrage au goût neutre.

Ce site a été développé dans le cadre de l'étude Hypocaps pour recueillir les retours d'utilisateurs via un questionnaire dynamique, et présenter le projet au public.

## Technologies

- **Next.js 15** (App Router + Pages Router)
- **React 19** + **TypeScript**
- **TailwindCSS**
- **Supabase** (PostgreSQL)
- **Algolia** (recherche)
- Contenu géré en fichiers JSON

## Fonctionnalités principales

- Questionnaire multi-étapes avec logique conditionnelle et validation
- Collecte et stockage des réponses dans Supabase
- Contenu éditable via fichiers JSON
